# Frontend Challenge 2026

Implementá un **popup de producto** de dos columnas que consuma datos de la API.

## Duración - 30 min

## Objetivos

Crear un popup que muestre un producto y cumpla lo siguiente:

1. **Imagen del producto a la izquierda** y **textos a la derecha**, respetando los mockups de referencia en la carpeta `[mockup/](mockup/)`.
2. Poder **abrirse y cerrarse** (botón de apertura y botón de cierre).
3. **Diseño responsive** para móvil y escritorio.
4. **Obtener los datos** desde la API; no usar datos hardcodeados.
5. **Utilizar `fetch`** para las peticiones HTTP.

## API

La URL base de la API es `https://lerenconsulting.com/apptiendanube`. Para recuperar los datos, enviá una petición **GET** a `/products/{uuid}` con el **UUID** del producto **`fc7ba3cd-9e62-409d-84df-7ccd64a17f59`**.
